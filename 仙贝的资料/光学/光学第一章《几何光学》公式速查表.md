# 光学第一章 几何光学 公式速查

## 符号规则（先定这个，错则全错）
- 角度顺时针为正
- 物距s、像距s'从顶点量，顺光线正、逆光线负
- 折射率真空=1，n=c/v
- 反射可看成 n'=-n 的折射特例

## 一、基本量
- c=λν，介质中频率不变、波长变 λ=λ₀/n
- 色散柯西公式：n=A+B/λ²+C/λ⁴；近似 n≈A+B/λ²
- 折射定律：n sinI=n' sinI'
- 反射定律：I=-I''
- 全反射临界角：sinθc=n₂/n₁（入射角>θc全反射）
- 费马原理：光线走光程 L=∫n ds 为极值的路径，统一推出直线/反射/折射

## 二、平面系统
- 单平面镜：s'=-s，β=1（镜像）；镜转θ→反射光转2θ
- 平面角镜夹角α：偏转角 β=2α；成像个数由 2π/α 决定
- 平面折射傍轴：n₁/s₁=n₂/s₂
- 平行平板：轴向位移 Δl'=L(1-1/n)；侧向 Δs=Δl'·sinI₁
- 折射棱镜：偏向角 δ=I₁+I₂'-α；最小偏向角 n=sin[(α+δmin)/2]/sin(α/2)
- 光楔：δ=(n-1)α；移动测微 Δy=ΔL(n-1)α
- 光纤数值孔径：NA=n₀sinφc=√(n₁²-n₂²)

## 三、球面系统
- 单球面折射：n'/s'+n/(-s)=(n'-n)/r
- 焦距：f'=n'r/(n'-n)，f=nr/(n-n')
- 高斯公式：f'/s'+f/(-s)=1
- 牛顿公式：xx'=ff'（x=s-f，x'=s'-f'）
- 垂轴放大率：β=ns'/(n's)
- 轴向放大率：α=ns'²/(n's²)=(n'/n)β²
- 角放大率：γ=s/s'
- 三者：αγ=β；β>0正立、β<0倒立；|β|>1放大
- 拉格朗日不变量：J=nyU=n'y'U'
- 球面反射：1/s'+1/s=2/r；β=-s'/s；平面镜 s'=-s
- 光焦度：Φ=(n'-n)/r=n'/f'=-n/f，单位D；Φ>0会聚、<0发散
- 薄透镜空气中：1/s'-1/s=1/f'；焦距 1/f'=(n-1)(1/r₁-1/r₂)；Φ=Φ₁+Φ₂
- 共轴球面系统：逐面成像，衔接 l(k+1)=l(k)'-d(k)

## 四、做题流程
1. 定符号规则、画图
2. 选公式：折射单球面、反射 1/s'+1/s=2/r、薄透镜 1/f'
3. 符号代入（物距负号）
4. 放大率判断虚实/正倒/大小
5. 多系统：像距作下一面物距

最易错：物距负号、反射折射公式别混、薄透镜别和单球面混
